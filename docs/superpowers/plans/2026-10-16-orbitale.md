# Orbitale Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Orbitale, a Windows 11 WinUI 3 app that stacks ~300 tripod night frames into a star-trail image. It removes plane and satellite trails, supports Lighten/Darken/Average, comet style and gap filling, and shows a live progressive preview.

**Architecture:** A UI-free engine library (`Orbitale.Engine`, OpenCvSharp + Magick.NET) does all decoding, trail removal, blending and saving. It's driven frame-by-frame by `StackEngine.RunAsync`, which reports progress with a ready-to-display preview. A WinUI 3 unpackaged app (`Orbitale.App`, MVVM) binds to it. A console harness (`Orbitale.Cli`) runs the same engine on the real 279-frame sequence to measure speed and memory and to judge the look.

**Tech Stack:** C# / .NET 10, Windows App SDK (WinUI 3, unpackaged, self-contained), CommunityToolkit.Mvvm, OpenCvSharp4 + OpenCvSharp4.runtime.win, Magick.NET-Q16-AnyCPU, xUnit.

**Spec:** `docs/superpowers/specs/2026-10-16-orbitale-design.md`. Read it before starting any task. The Python prototype `remove_trails.py` (repo root) is the reference implementation of trail removal.

## Global Constraints

- Windows 11, x64 only. Front end is WinUI 3 (Windows App SDK). The app is unpackaged (`WindowsPackageType=None`) and self-contained. No Store, no MSIX.
- Fully offline: no network calls, accounts or telemetry.
- Name "Orbitale". Never use StarStaX's name, logo, texts or look in the UI, assets or docs (except the spec's one reference line).
- Input formats: JPG, TIFF 8-bit, TIFF 16-bit, RGB. Output: JPG (quality 95, 8-bit) and TIFF (16-bit), full input resolution.
- The output carries the **ICC profile and basic EXIF of the first input frame**. EXIF Orientation is written as 1, because pixels are already oriented on read.
- Working precision: 32-bit float per channel, BGR, values 0..1 (`MatType.CV_32FC3`).
- Frames are processed in natural filename order (`IMG_9` before `IMG_10`), case-insensitive.
- Peak memory under ~8 GB for 45 MP frames. Performance target: 279 × 40 MP frames in a few minutes on the user's PC (i7-11700K, 8 cores / 16 threads, 32 GB, CPU only).
- The UI thread never runs image processing. Stop takes effect within about 1 s, and Start after Stop always restarts from the first frame.
- Real test sequence: `D:\JPG_star_trail` (279 JPGs, 7728 × 5152, ICC embedded). Read-only. Never copy it into the repo, never write into it.
- Package versions: add with `dotnet add package <id>` (latest stable). Don't pin prerelease versions.
- Every commit message ends with the line `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Non-ASCII paths** (e.g. `D:\Photos\Été 2026\…`): reading and saving must work. `Cv2.ImRead`/`ImWrite` fail on these on Windows, so decode from bytes. Test in Task 2.
2. **A frame that is a different size or corrupt** within the 300: it's skipped before the run with a message naming the file, and the run continues with the rest. Test in Task 3.
3. **Too few frames for the neighbour window** (1–4 frames, e.g. a short test): the run still works. With fewer than 3 frames trail removal is switched off and reported, otherwise *k* shrinks to fit. Test in Task 4.
4. **A sharp, straight, static bright feature** in the landscape (a lit ridge line, a hut light, a lake reflection edge): it must never be detected as a trail, because it's present in the neighbours. Test in Task 5.
5. **A 16-bit TIFF with an Adobe RGB profile in, 16-bit TIFF out**: depth and profile are preserved bit-exactly. Also 8-bit JPG in → 16-bit TIFF out. Test in Task 2.

## Pinned decisions (apply across tasks)

- **Detection scale.** Trail detection and star detection run on a copy downscaled with `InterpolationFlags.Area` so the long side is **2000 px**, the scale the prototype was validated at. If the frame is already ≤ 2000 px, no resize. Masks and positions are mapped back to full resolution. Repair and line drawing happen at full resolution.
- **Sensitivity mapping.** `σ = 4.0 − 2.5 · TrailSensitivity`, with default `TrailSensitivity = 0.6` (σ = 2.5). All other trail parameters are the prototype defaults at detection scale: star dilate 7 px ellipse, Gaussian 3×3, min blob 4 px, min length 0.03 × long side, max gap 25 px, Hough ρ=1, θ=π/720, threshold `max(20, minLen/2)`, min fill 0.35 (with the ±1 px row check), line width 7, mask dilate 5 px ellipse. Feather: Gaussian 7×7 at detection scale, i.e. kernel `odd(7·scale)` at full res, where `scale = fullLong / detectLong`.
- **Neighbours.** Default *k* = 2. The window is shifted inward at the sequence ends (prototype logic). `kEff = min(k, (n−1)/2)`. If `n < 3`, trail removal is off.
- **Comet.** Tail length `T = max(2, round(N · (1 − 0.9 · CometStrength)))` frames. Per-frame decay `d = 0.01^(1/T)`. Background `B` = running per-pixel minimum. Excess `E ← max(E · d, frame − B)`, clamped ≥ 0. Result `= B + E`. Head at start = process the frames in reverse order. Default `CometStrength = 0.5`.
- **Gap filling.** For each consecutive processed pair, detect stars in both (top-hat, detection scale), match them (mutual nearest within radius `r = 2 + 10 · GapFillStrength` px at detection scale, ratio test, local-motion consistency), and draw an anti-aliased line between the matched full-res positions onto the current frame (`max`) before blending. Unmatched stars draw nothing, so a star setting behind the ridge can't bleed into it. Default `GapFillStrength = 0.5`.
- **Preview.** While running, the long side is ≤ 2560 px. After Finished/Stopped, the app requests a full-resolution BGRA render for true 100 % zoom.

**Interfaces:**
- Produces:
  - `static Mat ImageReader.Read(string path)`. Returns `CV_32FC3`, BGR, 0..1. Decodes via `Cv2.ImDecode(File.ReadAllBytes(path), ImreadModes.AnyDepth | ImreadModes.Color)` (applies EXIF orientation). Scales by 1/255 or 1/65535 by depth. Throws `InvalidDataException` with the file name on failure.

  - `static void ImageWriter.Save(Mat image32f, string path, ImageMetadata meta)`. The format comes from the extension (`.jpg/.jpeg` → 8-bit q95, `.tif/.tiff` → 16-bit, ZIP compression). Applies ICC and EXIF with Orientation=1. Writes via a temp file in the same folder, then moves it, so a failed save never leaves a half file. Throws `NotSupportedException` for other extensions.

**Interfaces:**
- Consumes: `ImageReader.Read`, `ImageReader.ReadHeader`.
- Produces:
  - `sealed record SkippedFrame(string Path, string Reason)`.
  - `sealed class FrameSequence { IReadOnlyList<string> Files; IReadOnlyList<SkippedFrame> Skipped; int Width; int Height; static FrameSequence Build(IEnumerable<string> paths); }`. Natural, case-insensitive sort. Reference size = the header of the first readable file. Mismatched or unreadable files go to `Skipped` with the reasons `"size 4000×3000 differs from 7728×5152"` / `"unreadable: <message>"`. Throws `InvalidOperationException("No readable frames")` if none are left.
  - `sealed class FrameWindow : IDisposable { FrameWindow(IReadOnlyList<string> files, int capacity); Mat Get(int index); void Prefetch(int index); }`. LRU cache of decoded frames, with `capacity = 2k + 2`. Evicted Mats are disposed. `Prefetch` starts a background decode (one in flight at most), which `Get` awaits if it's the same index. Returned Mats are owned by the window, so callers must not dispose them.

### Task 7: Gap filling

**Files:**
- Create: `src/Orbitale.Engine/GapFill/StarDetector.cs`, `StarMatcher.cs`, `GapFiller.cs`
- Test: `tests/Orbitale.Engine.Tests/GapFill/GapFillerTests.cs`

**Interfaces:**
- Produces:
  - `readonly record struct Star(float X, float Y, float Radius, Vec3f Color)`, with full-res coordinates and radius (`sqrt(area/π)`). Color is the per-channel max in a 3×3 window at full res.
  - `static IReadOnlyList<Star> StarDetector.Detect(Mat frame32f, Mat? excludeMask8U = null)`. At detection scale: gray → top-hat (ellipse 9 px) → threshold `median + 5·MAD` → components with area 1..60 → intensity-weighted centroid, scaled to full res. Stars under `excludeMask` (removed trails, full res) are dropped.
  - `static IReadOnlyList<(Star Prev, Star Cur)> StarMatcher.Match(IReadOnlyList<Star> prev, IReadOnlyList<Star> cur, double radiusDetectPx, double scale)`. Uses a grid bucket with cell size = radius. Rules: (a) mutual nearest neighbours within radius; (b) the nearest must be < 0.67 × the second nearest (ratio test); (c) local motion consistency: within each 200 × 200 detection-px cell, drop matches whose displacement differs from the cell's median displacement by > 2 detection px (cells with < 3 matches keep their matches); (d) drop displacements < 0.5 full-res px.
  - `sealed class GapFiller { GapFiller(double strength); void Apply(Mat currentFrame, IReadOnlyList<Star> prevStars, IReadOnlyList<Star> curStars); }`. For each match, draw onto a black layer an anti-aliased line from prev to cur with thickness `max(1, round(1.6·Radius))` (mean of the pair) and color = per-channel `min(prev.Color, cur.Color)`. Then `Cv2.Max(currentFrame, layer, currentFrame)`. Radius `r = 2 + 10·strength` detection px.

Rules: Start is allowed in Idle/Finished/Stopped, disposes the previous Result and restarts from frame 1. Stop only while Running (→ Stopping → Stopped). Save only in Finished/Stopped.
